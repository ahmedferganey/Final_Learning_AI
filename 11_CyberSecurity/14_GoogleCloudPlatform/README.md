## Phase Goal

By the end of this phase, you should be able to:

- Manage Google Cloud organizations, folders, projects, billing, APIs, quotas, and labels.
- Configure IAM, service accounts, impersonation, federation, and organization policies.
- Design and operate VPC networks, Shared VPC, firewall policies, Cloud NAT, VPN, Interconnect, DNS, and load balancing.
- Deploy and operate Compute Engine, Managed Instance Groups, GKE, Cloud Run, and Cloud Run functions.
- Manage Cloud Storage, Filestore, Hyperdisk, NetApp Volumes, and Managed Lustre.
- Select and operate Cloud SQL, AlloyDB, Spanner, Firestore, Bigtable, Memorystore, BigQuery, Pub/Sub, and Dataflow.
- Configure Cloud Monitoring, Cloud Logging, Ops Agent, Prometheus, Trace, and operational alerts.
- Implement Cloud KMS, Secret Manager, Security Command Center, VPC Service Controls, and audit logging.
- Design backup, restore, RPO/RTO, and disaster-recovery procedures.
- Administer Google Cloud with `gcloud`, `bq`, `kubectl`, and Infrastructure-as-Code concepts.
- Troubleshoot identity, networking, compute, containers, storage, databases, and observability problems.
