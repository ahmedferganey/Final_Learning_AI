# Phase 1 — Computer & IT Foundations

This folder contains the seven Phase 1 learning modules in dependency order.

4. `04_Database_Fundamentals.md`

7. `07_Introduction_to_Cybersecurity.md`

## Recommended workflow

For each module:

1. Read the learning objectives.
2. Study the core concepts and reproduce the examples yourself.
3. Complete every hands-on exercise rather than only reading the commands.
4. Build the mini project and keep the deliverables in a separate portfolio folder.
5. Answer the self-assessment questions without looking at the answers first.
6. Revisit weak areas before moving to the next module.

## Phase 1 completion criteria

You are ready for Phase 2 when you can:

- Explain how an operating system manages processes, memory, storage, files, users, and devices.
- Explain how hosts communicate through Ethernet, IP, TCP/UDP, DNS, DHCP, routing, and ports.
- Write a small structured program using variables, conditions, loops, functions, and basic error handling.
- Model a small relational database and write basic SQL CRUD queries and joins.
- Convert a simple business problem into requirements, architecture, tasks, tests, and a release plan.
- Explain virtualization, hypervisors, cloud service models, deployment models, elasticity, availability, and shared responsibility.
- Explain assets, threats, vulnerabilities, risk, controls, CIA, authentication, authorization, least privilege, defense in depth, and basic incident handling.

The material is intentionally practical. Later phases will deepen each domain rather than repeating these foundations.
