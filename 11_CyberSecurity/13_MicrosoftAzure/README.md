## Phase Goal

By the end of this phase, you should be able to:

- Manage Microsoft Entra users, groups, and access.
- Configure Azure RBAC, Policy, locks, tags, subscriptions, and management groups.
- Implement and manage Azure Storage.
- Deploy and manage virtual machines, VM Scale Sets, containers, and App Service.
- Configure VNets, subnets, peering, NSGs, routing, Bastion, private endpoints, DNS, and load balancing.
- Monitor Azure resources with Azure Monitor, Log Analytics, KQL, alerts, and Network Watcher.
- Implement Azure Backup and Site Recovery.
- Administer Azure with Azure CLI, PowerShell, ARM templates, and Bicep.
- Troubleshoot identity, networking, compute, storage, monitoring, and recovery issues.
