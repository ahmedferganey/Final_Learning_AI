# Phase 12 — AWS Cloud Engineering

This phase moves from AWS fundamentals into architecture, operations, and managed application platforms.

## Courses

1. **52. AWS Certified Solutions Architect – Associate**
2. **53. AWS SysOps Administration**
3. **54. Amazon PaaS Web Services**

## Recommended Order

```text
AWS Architecture Design
        ↓
AWS Operations / CloudOps
        ↓
Managed Application Platforms
```

## Phase Goal

By the end of this phase, you should be able to:

- Design secure, resilient, high-performing, and cost-optimized AWS architectures.
- Operate and troubleshoot AWS workloads.
- Monitor AWS services with CloudWatch, CloudTrail, Config, and Systems Manager.
- Implement backup, recovery, scaling, security, and automation.
- Deploy web applications using managed AWS platforms.
- Select between EC2, Elastic Beanstalk, App Runner, ECS, EKS, Fargate, and Lambda.
- Build APIs and asynchronous systems using API Gateway, SQS, SNS, EventBridge, and Step Functions.
- Apply IAM, networking, observability, deployment, and cost best practices.

## Current Certification Note

The roadmap keeps the course name **AWS SysOps Administration**, but AWS has renamed the certification:

```text
Old:
AWS Certified SysOps Administrator – Associate (SOA-C02)

Current:
AWS Certified CloudOps Engineer – Associate (SOA-C03)
```

Course 53 is aligned to the current SOA-C03 CloudOps content.
