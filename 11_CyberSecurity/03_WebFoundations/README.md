# Phase 3 — Web Foundations

This phase contains three modules in the exact curriculum order:

1. `13_HTML5_and_CSS3.md`
2. `14_Client_Side_Technologies.md`
3. `15_Web_Fundamentals.md`

## Important Curriculum Note

The unified track does **not** list a standalone **JavaScript Fundamentals** course. Therefore JavaScript is not added as a fourth course in this phase.

The JavaScript required for browser-side development is taught inside:

**14. Client-Side Technologies**

That module includes:

- JavaScript values and syntax
- arrays and objects
- functions
- scope and closures
- modules
- DOM
- events
- forms
- asynchronous JavaScript
- promises / async-await
- Fetch API
- JSON
- browser storage
- cookies from the client perspective
- same-origin policy
- CORS
- browser debugging

This is sufficient foundation for the later Node.js and backend/API phases, although a future Node.js course should still include/review JavaScript prerequisites.

## Recommended Study Method

For every section:

1. Read the explanation.
2. Type the example manually.
3. Change the example and predict the result before running it.
4. Use browser Developer Tools to inspect what actually happened.
5. Complete the labs without copying finished solutions.
6. Complete the mini project.
7. Explain the concept aloud in your own words.

## Phase 3 Dependency Flow

```text
13. HTML5 and CSS3
        ↓
14. Client-Side Technologies
        ↓
15. Web Fundamentals
        ↓
Phase 4 — Networking
```

The final Web Fundamentals module intentionally connects browser concepts with DNS, transport, TLS, HTTP, caching, cookies, CORS, proxies, load balancers, and CDNs so that Phase 4 networking concepts have a practical web context.
