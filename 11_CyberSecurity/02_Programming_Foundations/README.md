## How to Study

Study one file at a time. Type examples yourself, complete labs before the mini project, and keep code in a study repository. Do not move forward because syntax looks familiar; move forward when you can explain decisions and debug your own mistakes.

## Exit Criteria

- Write useful Python automation from scratch.
- Compile and debug a small multi-file C program.
- Explain and apply core OOP principles.
- Choose common data structures and explain normal complexity tradeoffs.
- Write defensive Bash automation with quoting, exit-status handling, pipelines, functions, and safe filesystem operations.
