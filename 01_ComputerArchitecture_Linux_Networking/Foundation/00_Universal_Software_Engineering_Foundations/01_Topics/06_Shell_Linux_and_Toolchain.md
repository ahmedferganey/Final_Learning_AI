# Shell, operating environment and developer tools

> **Priority:** Core · **Study window:** 1 and 6 · **Approximate focused time:** 10–12 (overlaps with weekly plan)

## Why it is universal

Every specialty needs to navigate machines, troubleshoot toolchains and reproduce development environments.

## Detailed table of contents / concepts to cover

- [ ] Filesystem, absolute and relative paths, permissions and environment variables
- [ ] pwd, cd, ls, cat, grep, find, head/tail, pipes and redirection
- [ ] Processes, exit codes, logs, standard input/output/error
- [ ] Installing tools, virtual environments and dependency manifests
- [ ] Editors, debugger and terminal multiplexer: awareness before mastery
- [ ] Safe execution of downloaded scripts; understanding each command first

## How to learn it

1. Repeat each command on a disposable practice directory.
2. Complete a short assignment using the terminal rather than the file explorer.
3. Diagnose a deliberately broken PATH or dependency environment.

## Required exercise

Write a small shell script that runs program tests, saves test output, checks exit codes and reports failure.

## Independent exit criteria

- [ ] Can navigate a repository and search code from the terminal.
- [ ] Can activate a project environment and reproduce dependencies.
- [ ] Can distinguish shell, interpreter and OS errors.

## AI collaboration exercise

Ask an AI assistant for an alternative approach, at least three failure scenarios and a code/design review. Validate the suggestions independently, make one targeted improvement and describe what you accepted or rejected and why. Never treat the AI answer itself as evidence of correctness.
