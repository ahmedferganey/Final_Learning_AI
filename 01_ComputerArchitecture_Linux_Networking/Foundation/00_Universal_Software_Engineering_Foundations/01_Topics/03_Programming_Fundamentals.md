# Programming fundamentals with one transferable language

> **Priority:** Core · **Study window:** 2–3 · **Approximate focused time:** 24–30 (overlaps with weekly plan)

## Why it is universal

A main language is a vehicle for learning universal programming concepts, not an early career commitment.

## Detailed table of contents / concepts to cover

- [ ] Variables, types, values, operators, Boolean logic and control flow
- [ ] Functions, parameters, return values, pure functions and side effects
- [ ] Strings, sequences, dictionaries/maps and sets
- [ ] Iteration, comprehensions and generators at introductory level
- [ ] Modules, imports, packages, environments and package management
- [ ] Exceptions, validation, meaningful errors and file I/O
- [ ] JSON and CSV, basic typing, objects, composition and simple classes
- [ ] Mutability, references, scope and the difference between equality and identity

## How to learn it

1. Choose Python as the default teaching language; JavaScript or Java is fine if already familiar. Do not study two from scratch concurrently.
2. Build each function alone and write 2–4 tests.
3. Step through bugs in a debugger rather than repeatedly guessing.
4. Read documentation for unfamiliar APIs; compare AI-written variants only after understanding one.

## Required exercise

Create a CLI notes or expense tracker that validates input, reads and writes JSON, and separates business logic from input/output.

## Independent exit criteria

- [ ] Can create functions and modules without autocomplete.
- [ ] Can explain state, mutation and exception behavior.
- [ ] Can add a new feature and tests to an unfamiliar small program.

## AI collaboration exercise

Ask an AI assistant for an alternative approach, at least three failure scenarios and a code/design review. Validate the suggestions independently, make one targeted improvement and describe what you accepted or rejected and why. Never treat the AI answer itself as evidence of correctness.
