# Week 06 — Linux, operating systems and concurrency overview

**Time budget:** approximately 15 focused hours.

## Objective

Work with shell, processes, permissions, I/O and basic execution models.

## Topic guides

- [Shell, operating environment and developer tools](../01_Topics/06_Shell_Linux_and_Toolchain.md)
- [Operating systems, processes and concurrency](../01_Topics/08_Operating_Systems_and_Concurrency.md)

## Suggested study sessions

1. **Session 1 (~3h):** Read core theory, write goal and acceptance criteria; reproduce a tiny example.
2. **Session 2 (~3h):** Solve small problems independently; push a minimal working commit.
3. **Session 3 (~3h):** Extend the weekly project with input validation and edge cases.
4. **Session 4 (~3h):** Add tests, debug a failure, compare one AI alternative and review the diff.
5. **Session 5 (~3h):** Complete deliverable, write notes/README, demonstrate your solution and assess gaps.

Adapt session timing to the topic; avoid spending the entire week watching lectures.

## Deliverable

Shell test runner; process/log investigation; short concurrency failure note.

## Independent checkpoint

Distinguish CPU vs. I/O bottlenecks and explain one race-condition scenario.

## End-of-week checklist

- [ ] I completed the required deliverable and can demonstrate it.
- [ ] I can explain the important decisions unaided.
- [ ] I tested normal, boundary and failure conditions.
- [ ] I inspected all AI-generated changes and verified the behavior independently.
- [ ] I recorded one error, the cause and a reproduction of its fix.
- [ ] I linked the evidence in my weekly progress tracker.
