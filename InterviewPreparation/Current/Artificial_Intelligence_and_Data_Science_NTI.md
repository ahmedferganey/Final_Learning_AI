# Artificial Intelligence and Data Science

## First Semester

### SWI551: Mathematical Foundations and Software Development

**Mathematical foundations**
- Linear algebra for AI
- Limits and differentiation, including partial derivatives
- Chain rule and backpropagation in neural networks
- Gradient descent optimization: vanilla gradient descent, Momentum, and Adam
- Integral calculus for probability distributions
- Convex versus non-convex optimization, loss functions, and cost minimization
- L1 and L2 regularization
- Constrained optimization using Lagrange multipliers

**Model evaluation and software development**
- Model evaluation metrics: accuracy, precision, recall, F1-score, and AUC-ROC
- Coding standards
- Software Development Life Cycle (SDLC) for AI projects
- Debugging and code optimization techniques

### SWI552: Data Engineering & Analysis

**Data engineering**
- Introduction to data engineering and analysis
- Tools: SQL, pandas, and related technologies
- Data collection and storage, including cloud storage and database sources
- Data cleaning and transformation through ETL pipelines
- Automated data workflows

**Data analysis and reporting**
- Exploratory Data Analysis (EDA)
- Statistics and feature engineering
- Correlation analysis
- Data visualization with Matplotlib and Seaborn
- Power BI dashboards
- Real-world reporting

### SWI553: Artificial Intelligence Concepts and Machine Learning Techniques

**Data preparation and feature engineering**
- Machine learning workflows
- Data preprocessing: missing values and outlier handling
- Feature scaling: normalization and standardization
- Categorical encoding: one-hot encoding and label encoding
- Dimensionality reduction techniques

**Supervised learning**
- Regression: linear regression, polynomial regression, Ridge, and Lasso
- Classification: logistic regression, decision trees, and Support Vector Machines (SVM)
- Ensemble methods, including XGBoost
- Model evaluation: RMSE for regression; precision, recall, and other classification metrics
- Hyperparameter tuning

**Unsupervised learning and neural networks**
- Clustering, including k-means
- Anomaly detection
- Neural networks and Multilayer Perceptrons (MLPs)

## Second Semester

### SWI554: Deep Learning Techniques and Computer Vision

**Deep learning foundations**
- Neural network architectures: MLPs, CNNs, and RNNs
- Backpropagation and optimization using methods such as Adam
- Regularization and optimization: dropout, batch normalization, and techniques to combat overfitting

**Computer vision and sequence models**
- Convolutional Neural Networks (CNNs) and vision architectures, including ResNet and YOLO
- Transfer learning and pretrained models, including those trained on ImageNet
- Recurrent models and transformers for sequence processing, including LSTM and BERT

**Generative modeling and applications**
- Generative Adversarial Networks (GANs)
- Variational Autoencoders (VAEs)
- Generative modeling challenges, including mode collapse
- Applications across computer vision, NLP, and predictive analytics

### SWI555: Natural Language Processing

**Traditional NLP**
- Evolution from rule-based NLP to neural approaches
- Tokenization, TF-IDF, and n-grams
- Word embeddings, including Word2Vec

**Transformers and pretrained language models**
- Transformer architecture: self-attention and positional encoding
- BERT and masked language modeling
- GPT and text generation
- Transfer learning and fine-tuning pretrained models for domain-specific tasks

**Applications**
- Sentiment analysis
- Machine translation
- Chatbots

### SWI556: Industry Project in Artificial Intelligence

Apply AI knowledge to a real-world problem through a structured, instructor-guided project.

**Project workflow**
1. **Proposal submission:** Define the problem, objectives, and proposed solution.
2. **Research and design:** Investigate approaches and refine the design using instructor feedback.
3. **Implementation and testing:** Develop, evaluate, and improve the solution.
4. **Documentation:** Record methodology, implementation, results, and findings.
5. **Presentation:** Communicate the project and its outcomes.

**Learning outcomes:** Integrate technical AI development, project management, research, documentation, and presentation skills to produce an actionable solution.
