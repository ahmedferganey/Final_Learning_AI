# Artificial Intelligence (AI) — Module Details

| Field | Details |
|---|---|
| **Module Name** | Artificial Intelligence (AI) |
| **Department in Charge** | Electronics |
| **Duration** | 80 Hours |

## Module Description

- This course develops students' capabilities in Python programming, mathematics for AI, data analysis, machine learning, and deep learning algorithms. It provides the skills needed to understand the basic principles of modern AI, machine learning, and deep learning, and lays a foundation for future AI project planning and solution design.
- Trainees study through official Huawei Academy materials and take online academy exams, which can qualify them for a discount voucher for the international certification exam.

## Target Audience

Engineers and graduates from the following fields:

- Communications and Electronics Engineering
- Computer Engineering
- Mechatronics Engineering
- Biomedical Engineering
- Information and Computer Science

## Course Prerequisites

- Basic Python programming principles
- Basic mathematics

## Course Contents

After completing this course, trainees will have studied:

1. Artificial Intelligence Overview
2. Python Programming Basics
3. Mathematics for AI
4. Introduction to Data Analysis
5. Machine Learning
6. Deep Learning
7. AI Development Framework
8. Introduction to Huawei AI Platforms
9. Cutting-edge AI Applications
10. Quantum Computing and Machine Learning
