> **Program objective:** Gain practical skills in Big Data and Data Science for research and industry, including large-scale data processing, machine learning, analytics, and applied, end-to-end problem solving.

## 1. Program Overview

The Big Data and Data Science (BD&DS) Professional Diploma is a structured professional program designed to give participants a foundation in the principles, methodologies, and applications of Big Data and Data Science.

The program consists of **four specialized courses and an applied group project**. Participants integrate the knowledge, analytical competencies, and practical skills acquired during their studies. The courses are selected from Informatics program offerings within Nile University's School of Information Technology and Computer Science, combining academic rigor with professional relevance.

### What You Will Learn

- Understand Hadoop cluster architecture at the hardware and system-software levels.
- Use Hadoop and related technologies—including MapReduce, Spark, Hive, Impala, and Pig—to build analytics applications for enterprise-scale problems.
- Use advanced tools and technologies to analyze data.
- Understand essential concepts in data mining and Big Data analytics.
- Apply cloud-based machine learning and data analysis technologies to real-world problems.
- Combine Big Data engineering and statistical or machine learning methods to develop practical solutions.

## 3. Detailed Course Descriptions

### CIT-650 — Introduction to Big Data, Hadoop and Spark (Required)

The capacity to collect and store enormous volumes of varied data creates a need for new methods of efficient processing and analysis. As the Big Data landscape evolves, new technologies emerge and existing technologies mature.

This course provides comprehensive coverage of **Apache Spark** and key components of the **Hadoop ecosystem**, with an emphasis on developing end-to-end applications that process Big Data efficiently. Students learn fundamental concepts and apply relevant tools to solve data processing challenges encountered by enterprises and research institutions.

**Key technologies and themes**

- Big Data processing architectures and approaches.
- Spark and the Hadoop ecosystem.
- End-to-end Big Data application development.
- Efficient processing and analysis of large-scale datasets.
- Enterprise and research use cases.

### CIT-651 — Introduction to Machine Learning and Statistical Analysis (Required)

This course introduces machine learning and statistical data analysis. It develops a foundation in probability theory, statistics, and techniques for statistical inference and predictive modeling.

**Statistical foundations**

- Basic probability theory.
- Statistics and statistical data analysis.
- Parameter estimation.
- Hypothesis testing.
- Regression analysis.

**Machine learning methods**

- Bayes classifiers.
- K-nearest neighbors (K-NN).
- Decision trees.
- Support vector machines (SVM).
- K-means clustering.
- Principal component analysis (PCA).
- Independent component analysis (ICA).
- Neural networks.

Students also learn to tackle real-world problems using modern technologies for cloud-based machine learning computation and data analysis.

### CIT-652 — Advanced Big Data Analytics Technologies and Applications

This applied course brings together knowledge of **Big Data technologies** (such as Hadoop and Spark) and **Data Science methods** (including statistics and machine learning) to solve real-world application problems.

It also introduces current technological and scientific trends and examines how modern enterprises apply Big Data and data science.

**Application areas include:**

- Network traffic analysis.
- Text analytics.
- Financial applications.
- Other real-world enterprise data challenges.

### CIT-690A — Selected Topics in Deep Learning

This introductory course builds the understanding and practical skills needed to begin applying deep learning models.

**Core architectures**

- Convolutional neural networks and related convolutional architectures.
- Recurrent neural networks.
- Autoencoders.

**Application areas**

- Image classification.
- Text generation.
- Signal processing.

### CIT-690B — Advanced Methods and Applications in Data Science

Data Science combines theories, methods, and technologies from multiple disciplines to address complex data problems and help organizations transform their operations. Building on machine learning concepts introduced in **CIT-651**, this course puts theoretical methods into practical, real-life use cases.

Hands-on labs reinforce earlier learning and emphasize delivering measurable business value. Students are also introduced to the way real customer engagements work, including consulting and implementation approaches.

**Tools and technologies demonstrated**

- R.
- Java and Spring.
- Weka.
- Hadoop and Spark.
- Giraph.
- Cloud Foundry.
- MADlib.
- Greenplum.

**Practical emphasis**

- Applying machine learning in a business or customer context.
- Developing solutions for real data-related problems.
- Understanding consulting and implementation workflows.
- Evaluating relevant open-source and commercial tools.

## 4. Hands-on Group Project Based on a Real-Life Case

The applied project integrates material learned throughout the diploma into an **end-to-end, customer-like engagement**. Participants apply Big Data technologies and Data Science methods to an industry-driven problem under faculty or project-supervisor mentorship.

**Project format**

- Typically **five students per group**.
- Approximately **six weeks of mentorship**.
- Each group selects a project topic.
- Work follows the industry-driven **CRISP-DM lifecycle**.
- Teams progress through key milestones and produce a final solution.
- Each group presents its work for discussion and evaluation.

The project is intended to strengthen applied technical expertise, collaboration, problem solving, and experience delivering a data-driven solution.

## 5. Intended Audience

The diploma is aimed at technically grounded professionals who want to deepen their ability to work with large, complex datasets and translate analysis into practical results. Relevant backgrounds include programming, enterprise information systems, data analytics, statistics, and mathematics.

### Software Developers and Engineers

Developers with hands-on programming experience—preferably in **Java and Python**—and a good understanding of enterprise information systems who want to move into Data Science.

### Data and Business Intelligence Professionals

Professionals experienced in data warehousing, business intelligence, or data analysis who want to use modern technologies to work with larger and more complex datasets.

### Analytical and Quantitative Thinkers

Professionals with foundations in **probability, statistics, linear algebra, and mathematics** who want to apply those skills to real-world data challenges.
