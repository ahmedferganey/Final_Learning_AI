# Cloud DevOps Accelerator — D001

![Cloud DevOps Accelerator](https://nti.sci.eg/dey/images/tracks/D001.jpg)

## Part 1: Technical Program — Duration: 294 Hours

### Overview

- A “DevOps Accelerator” is a subcategory of Professional Services. It means that the provider has a proven, systematic, and repeatable process to help companies achieve a certain level of organizational “DevOps” maturity.
- This track targets Computer, Communication & Electronics Engineers in addition to graduates of the Faculty of Computer and Information. It leads to many international certificates such as Red Hat Certified System Administrator (RHCSA) exam (EX200), Red Hat Certified OpenShift Administrator exam (EX280), Amazon Cloud Practitioner AWS (CLF-C01), AWS Certified Solutions Architect – Associate (SAA-C03), and AWS Certified Security – Specialty exam (SCS-C03).

### Prerequisites

- CCNA.
- Fundamentals of Linux and Cloud Concepts.

### Contents

- Cloud and Virtualization Concepts.
- Linux Red Hat System Administration (RHCSA).
- AWS Cloud Practitioner.
- AWS Solutions Architect.
- AWS Cloud Security Foundations.
- Red Hat Enterprise Linux Automation with Ansible (RH294).
- Kubernetes/Helm.
- Red Hat OpenShift Introduction to Containers.
- Red Hat OpenShift Development I (DO188).
- Red Hat OpenShift Administration I (DO180).
- Infrastructure-as-Code (IaC) Tools for cloud: Terraform/CloudFormation/Ansible.
- Version control tools: Git.
- CI/CD Tools: GitLab/Jenkins.
- Capstone Project.

### Hands On

- Labs using simulation tools.
- Labs using virtual machines.
- Labs using remote cloud labs.

### Job Profiles

- Cloud DevOps Engineer.
- DevOps/SecDevOps Engineer.
- System Admin Engineer.
- Cloud Infrastructure Engineer.
- OpenShift Engineer.

## Part 2: Career Development — Duration: 126 Hours

### Overview

- This comprehensive course is designed for aspiring professionals in the ICT field who aim to excel in international business environments. Participants will develop proficiency in Business English, enabling them to confidently communicate and present in professional settings. Through hands-on simulations and workshops, attendees will practice leadership and team-building skills, fostering autonomy and critical thinking.
- The course also covers essential soft skills, including effective communication, time management, and problem-solving. Additionally, participants will gain a solid foundation in project management, equipping them with the tools to manage projects efficiently across various industries, such as Construction, Information Technology, and more.
- A new focus on essential workplace skills will prepare participants to thrive in a corporate environment, covering key areas such as teamwork, conflict resolution, and professional ethics.

#### Capstone Project

- **Project Development:** Participants will prepare their Capstone Projects throughout the course, integrating skills and knowledge from Business English, Career Development, Project Management, and Essential Workplace Skills. This ongoing project allows students to apply their learning in a practical and cohesive manner.
- **Presentation (6 Hours):** On the final day, participants will present their Capstone Projects. This session will showcase their ability to effectively communicate, manage projects, and demonstrate the essential skills they have acquired.
