## Part 1: Technical Program - Duration: 294 Hours.

### Overview:

- In today’s competitive business environment, both operational efficiency and robust security are crucial for maintaining the trust of users and clients. As organizations increasingly rely on rapid software development and deployment, integrating security practices throughout the entire software development lifecycle has become crucial. This necessity has led to the evolution of DevSecOps, an advanced iteration of DevOps that emphasizes the integration of security practices throughout the software development lifecycle. This course is meticulously designed to equip learners with the skills, tools, and practices to embed security in every aspect of software delivery while retaining the speed and agility offered by DevOps. This is through studying a series of advanced topics. First, you will learn the basics needed for DevOps such as Linux, Bash script, Python, Agile, Docker, and Kubernetes. Second, you will be taught DevOps and Public Cloud Computing. This includes Amazon Web Services (AWS) fundamentals, Terraform, Ansible, OpenStack Cloud Platform, and CI/CD Pipeline.
- After completing this track, you will be able to:
  - Understand the fundamentals of the Linux operating system.
  - Automate manual tasks using Python and Bash scripts.
  - Deploy, secure, and manage microservices in containers on Kubernetes.
  - Adopt an Agile and DevSecOps mindset for secure and fast delivery.
  - Plan and design secure technology solutions on public cloud platforms like AWS and OpenStack.
  - Develop secure Infrastructure as Code (IaC) using Terraform and Ansible.
  - Build a secure CI/CD pipeline incorporating continuous security checks and automated security testing.
  - Pass the DASA DevOps Fundamentals and Certified DevSecOps Professional exams.
  - Undertake the AWS Solutions Architect Associate (SAA - C02) exam.

Participants will develop proficiency in Business English, enabling them to confidently communicate and present in professional settings. Through hands-on simulations and workshops, attendees will practice leadership and team-building skills, fostering autonomy and critical thinking.
- The course also covers essential soft skills, including effective communication, time management, and problem-solving. Additionally, participants will gain a solid foundation in project management, equipping them with the tools to manage projects efficiently across various industries, such as Construction, Information Technology, and more.
