## Part 1: Technical Program - Duration: 294 Hours.

### Overview:

- In the past few years, an enormous amount of data has been produced compared to thousands of years of human history before. This bigdata represents a goldmine of commercial value and is very important source for policy makers. On the other hand, machine learning (ML) algorithms are more effective due to the large size of training data sets. Therefore, the value returned from combining big data with machine learning is expected to double. Machine learning algorithms help us keep up with the constant flow of data, while the volume and variety of data itself feeds the algorithms and helps them grow.
- The future of bigdata and machine learning appears promising to provide huge opportunities in the Job market due to the immense need for bigdata professionals.
- In this course, trainees learn the Linux essentials needed for Hadoop platforms. Then, they will learn Python programming and focuses on the history, features, and application fields of the Python language, the basic syntax and advanced usage of Python, and learning the modules frequently used in Python programming, such as pandas, and Scikit-learn. Additionally, it gives trainees a brief overview of how to process data using Structured Query Language (SQL).
- Development trend of the bigdata industry, big data features with basic technical principles of common and important bigdata components (including HDFS, HBase, Hive, MapReduce, YARN, Spark, Flink, Flume, Kafka, Elasticsearch, Zookeeper).
- You’ll learn how to store, manage, and analyze different types of data. In addition, you will learn how to select the correct bigdata stores for disparate data sets, process large data sets using Hadoop and Spark to extract value, query large data sets in near real time with Hive, and plan and implement a bigdata strategy for your organization.
