# AI-Powered Software Development

## First Semester

### SWI561: Foundations of Software Development

- **Programming fundamentals:** Python, Java, and JavaScript; variables, control structures, functions, and data types.
- **Object-oriented programming:** Core OOP concepts and their application in software development.
- **Data structures and algorithms:** Arrays, lists, stacks, and queues; algorithmic thinking and problem-solving strategies.
- **Software engineering practices:** Software Development Life Cycle (SDLC), Agile methodology, and DevOps principles.
- **Version control:** Git and GitHub.
- **Software quality:** Unit testing, debugging techniques, and performance optimization basics.
- **AI-assisted development:** Introduction to tools such as GitHub Copilot for code generation and error correction.

### SWI562: Frontend Development & User Experience

- **Web fundamentals:** HTML, CSS, and JavaScript.
- **Frontend frameworks:** React, Angular, and Vue.js; component-based UI development.
- **Responsive design:** Mobile-first and responsive design strategies.
- **UI/UX fundamentals:** Usability, accessibility, and visual hierarchy; wireframing, prototyping, and usability testing.
- **AI-enhanced interfaces:** AI-based UI personalization, automated theme generation, and behavior prediction.
- **State management:** Redux and React Context API.
- **Performance and discovery:** Lazy loading, code splitting, frontend performance optimization, and SEO techniques.
- **Deployment:** Deploying frontend applications to cloud platforms.

### SWI563: Backend Development & Databases

- **Backend technologies:** Django, Spring Boot, and Node.js.
- **API development:** RESTful and GraphQL APIs, asynchronous operations, and WebSockets.
- **Relational databases:** MySQL and PostgreSQL; database schema design and data modeling.
- **NoSQL systems:** MongoDB and Firebase.
- **Identity and security:** OAuth, JWT, secure data handling, encryption practices, and defenses against SQL injection, XSS, and CSRF.
- **AI-assisted operations:** AI-based database query optimization and anomaly detection in backend services.
- **Backend performance:** Performance tuning and service deployment.
- **Integration:** Connecting backend systems with frontend applications and third-party services.

## Second Semester

### SWI564: DevOps, Cloud Computing & AI-Driven Automation

- **CI/CD:** Jenkins, GitHub Actions, and GitLab CI.
- **Infrastructure as Code and automation:** Terraform and Ansible.
- **Observability:** Prometheus and Grafana for monitoring, with log analysis supported by AI tools.
- **Cloud platforms:** AWS, Microsoft Azure, and Google Cloud.
- **Containers and orchestration:** Docker, Kubernetes, and Docker Swarm.
- **Deployment architectures:** Microservices, serverless computing, and secure cloud-based application deployment.
- **AI-driven operations:** Anomaly detection, intelligent system monitoring, and predictive analytics for proactive maintenance.
- **Quality and governance:** Automated testing, deployment validation, cloud security policies, compliance, and access control.

### SWI565: Advanced Software Development & Security

- **Software architecture:** Microservices, layered architecture, event-driven architecture, and advanced design patterns.
- **Distributed-system qualities:** Scalability, concurrency, and fault tolerance.
- **Cybersecurity fundamentals:** Confidentiality, integrity, and availability (CIA).
- **AI for security:** AI-driven threat detection and intrusion prevention systems; automated vulnerability scanning.
- **Application security:** Authentication, authorization, encryption standards, secure APIs, and secure software development practices.
- **AI-assisted quality assurance:** AI-powered testing automation using tools such as Selenium and Cypress with AI-assisted workflows; regression testing and code review automation.
- **Security assessment:** Security auditing and penetration testing.

### SWI566: Full-Stack Software Development Capstone

Develop an end-to-end application that integrates frontend and backend components and addresses a real-world software challenge.

- **Project delivery:** Apply Agile project management and collaborate through Git and GitHub.
- **Full-stack implementation:** Build RESTful APIs, integrate frontend and backend components, and manage state across the application.
- **User experience:** Create responsive interfaces following UI/UX principles.
- **Security and data:** Implement authentication and secure database connections.
- **Performance:** Profile and optimize application performance.
- **AI-assisted engineering:** Use AI tools for code analysis and testing.
- **Deployment:** Deploy the full-stack solution to a cloud environment.
- **Communication and review:** Produce project documentation, conduct peer reviews, and deliver a final project presentation.
