# 13. Topics to Deprioritize During the First Year

These topics are useful but should not displace the primary stack unless a specific target role requires them.

## Additional programming languages

- C#
- Rust
- Julia
- deep Scala specialization

Java may be useful for some enterprise environments, but it is not a first-year priority for the chosen AI/Data engineering path.

## Frontend specialization

Do not spend a full term on:

- React
- Angular
- Vue
- Redux
- advanced UI / UX
- SEO
- advanced frontend optimization

For demos, prefer:

- Streamlit
- Gradio
- basic HTML / CSS / JavaScript
- basic React only if later required

## BI specialization

Do not spend major time on:

- Tableau
- Qlik
- MicroStrategy
- QuickSight

Power BI remains useful but should not replace core engineering work.

## Deep embedded / IoT specialization

Deprioritize initially:

- Android Camera HAL
- Qualcomm-specific optimization
- MediaTek-specific optimization
- Exynos-specific optimization
- OpenCL
- Vulkan
- OpenGL ES
- ISP integration
- Yocto
- deep Embedded Linux specialization

These are particularly relevant for specialized Valeo, Siemens, Luxoft, and embedded / Edge AI roles.

## Specialized research topics

Deprioritize unless directly required:

- quantum computing
- formal methods
- computational photography
- advanced speech specialization
- operations research specialization
