## AWS Certification Path

For the target career path:

> **AI / ML Engineer + Data Engineering + GenAI / Agentic AI + MLOps**

the recommended AWS certification progression is:

    AWS Certified Cloud Practitioner
                  ↓
    AWS Certified Solutions Architect – Associate
                  ↓
    AWS Certified Data Engineer – Associate
                  ↓
    AWS Certified Machine Learning Engineer – Associate
                  ↓
    Production RAG + Agentic AI + MLOps Experience
                  ↓
    AWS Certified Generative AI Developer – Professional

---

### 1. AWS Certified Cloud Practitioner

**Priority:** Foundation

Build basic AWS knowledge around:

- IAM
- EC2
- S3
- VPC
- RDS
- DynamoDB
- Lambda
- ELB
- Auto Scaling
- CloudWatch
- SQS / SNS
- AWS security fundamentals

Do not spend excessive time here.

> The goal is AWS familiarity before moving into technical Associate-level certifications.

**AWS AI Practitioner:** Optional.

Because the learning roadmap already covers ML, Deep Learning, LLMs, RAG, and Agentic AI, it is not necessary to collect another foundational certification.

---

### 2. AWS Certified Solutions Architect – Associate

**Priority:** Essential

This should be the main general AWS certification before specialization.

Focus on:

- Cloud architecture
- IAM
- VPC and networking
- Compute
- Storage
- Databases
- Load balancing
- High availability
- Scalability
- Fault tolerance
- Disaster recovery
- Serverless architecture
- Security
- Monitoring
- Cost optimization

Typical AI architecture:

    Users
      ↓
    API Gateway / Load Balancer
      ↓
    FastAPI / ECS / EKS / Lambda
      ↓
    RDS / DynamoDB / Redis
      ↓
    S3
      ↓
    ML / LLM Services
      ↓
    CloudWatch

This provides the architecture foundation required for Data Engineering, ML Engineering, MLOps, and GenAI systems.
