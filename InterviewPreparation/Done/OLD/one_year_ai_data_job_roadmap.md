# One-Year AI / Data / Agentic AI Job Roadmap

## Goal

Build a focused skill set over **12 months (October 2026 → September 2027)** that combines the **Nile University Big Data & Data Science Professional Diploma** with the highest-value technical skills repeatedly requested by companies such as:

- Microsoft
- Amazon / AWS
- Procore Technologies
- talabat
- Careem
- Capgemini
- noon
- Incorta

- PwC ETIC
- Siemens
- Valeo
- Luxoft
- Dell Technologies
- EFG Holding
- Jumia
- MNT-Halan
- _VOIS / Vodafone
- Orange Business
- IBM Egypt

The objective is **not** to learn every technology in the full job-skill catalog.

The objective is to become competitive for roles such as:

1. **AI / ML Engineer**
2. **Data Scientist**
3. **Data / AI Engineer**
4. **Junior–Mid Data Engineer**
5. **GenAI / Agentic AI Engineer**
6. **MLOps / AI Platform Engineer — entry path**

---

# 1. Strategy

The job-market file contains skills from several different career tracks:

- Data Science
- Machine Learning
- Deep Learning
- Data Engineering
- Big Data
- Generative AI
- Agentic AI
- MLOps
- Backend Engineering
- Cloud Engineering
- IoT
- Edge AI
- Computer Vision
- BI / Analytics

Trying to master all of them in one year would create shallow knowledge.

The recommended approach is therefore:

> **Strong ML/Data foundation + production software engineering + Big Data + GenAI/Agentic AI + MLOps/cloud.**

This combination has the broadest overlap across the target companies.

# 18. One-Year Outcome

```text

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓
```
