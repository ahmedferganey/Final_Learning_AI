# Notes on Deduplication

The catalog intentionally avoids repeating the same skill under multiple headings. Examples of normalization applied:

- `Google Cloud`, `Google Cloud Platform`, and `GCP` → **Google Cloud Platform (GCP)**
- `Gen AI` and `Generative AI` → **Generative AI (GenAI)**
- `Large Language Model` and `LLM` → **Large Language Models (LLMs)**
- `Retrieval Augmented Generation` and `RAG` → **Retrieval-Augmented Generation (RAG)**
- `K8s` and `Kubernetes` → **Kubernetes**
- `CI CD`, `CI/CD pipelines`, and similar wording → **CI/CD**
- `Data pipeline`, `ETL pipeline`, and `data processing pipeline` are separated only when the underlying capability is materially different.
- Product-specific services remain separate when employers explicitly request hands-on experience with them.
