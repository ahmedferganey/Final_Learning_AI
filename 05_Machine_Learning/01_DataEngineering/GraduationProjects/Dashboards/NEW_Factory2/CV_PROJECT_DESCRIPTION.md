# Recommended CV Entry

## Project Name
**Manufacturing Performance & Loss Analytics Platform | Power BI**

## One-line Description
Designed a Power BI manufacturing intelligence solution that integrates production, process-loss, quality, rework, and job-change data, with line-to-section-to-cavity loss attribution and capacity-weighted loss KPIs.

## CV Bullets
- Built a 5-page Power BI analytics solution covering FPY/pack efficiency, production gaps, process losses, product/order performance, quality/rework, job-change efficiency, and downtime-reason analysis.
- Designed a dimensional semantic model across production, process-loss, quality, rework, and job-change facts, supported by governed Excel inputs, stable event IDs, data validation, and reconciliation rules.
- Extended loss analysis from line level to **13-section × up-to-3-cavity** asset granularity and implemented capacity-weighted equivalent loss hours and estimated lost-unit calculations to prioritize high-impact sections and cavities.
- Developed DAX measures for KPI ratios, T1/T2 target variance, ranking, dynamic conditional formatting, Top-N analysis, and context-aware executive reporting.
